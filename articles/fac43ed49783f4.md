https://zenn.dev/gsy0911/articles/0a8e0e2156579d

という記事を書いてから毎日Taskfileを使っています。そんなTaskfileの実行をちょっと便利にする方法を紹介します。
zshを使っている場合に限ります。

# はじめに

zennの記事を書く際には以下のような Taskfile.yaml を作成しています。

```Taskfile.yaml
version: '3'

tasks:
  article:
    desc: create new article
    cmds:
      - npx zenn new:article
```

その上で `$ task article` とすると、`cmds`の内容を実行してくれます。

# Task 実行時に引数を与える場合

タスクがシンプルな場合だと全然問題ないですが、Taskfileはいろいろなパターンを考慮して、引数を与える場合があります。
その最たる例がデプロイのコマンドなどです。

```Taskfile.yaml
version: '3'

tasks:
  cdk-deploy:
    desc: deploy cdk
    dir: infrastructure
    cmds:
      - cdk deploy --context env={{.env}}
```

このコマンドは`$ env=dev task cdk-deploy`のように実行します。
与える引数が1つだけでenvのようにわかりやすいものだといいのですが複数個ある場合には途端に入力が大変になります。

簡単な回避策としては


```diff:Taskfile.yaml
version: '3'

tasks:
+ default:
+   cmds:
+     - task -l

  cdk-deploy:
-   desc: deploy cdk
+   desc: deploy cdk. example $ env=(dev|stg|prod) task cdk-deploy
    dir: infrastructure
    cmds:
      - cdk deploy --context env={{.env}}
```

のようにdefaultのコマンドを付与した上で、`$ task | grep cdk-deploy`などとするとコマンド例とともに見えます。しかし、入力の手間は変わっていません。

# Task 実行時に引数を制限する

また、Taskfile の機能で引数の入力を制限することもできます。

```diff:Taskfile.yaml
version: '3'

tasks:
  default:
    cmds:
      - task -l

  cdk-deploy:
    desc: deploy cdk. example $ env=(dev|stg|prod) task cdk-deploy
    dir: infrastructure
    cmds:
      - cdk deploy --context env={{.env}}
+   requires:
+     vars: [env]
```

こうすると、引数に env を求められます。
また、enum を指定するとenum以外の値を入力するとエラーにすることもできます。



```diff:Taskfile.yaml
version: '3'

tasks:
  default:
    cmds:
      - task -l

  cdk-deploy:
    desc: deploy cdk. example $ env=(dev|stg|prod) task cdk-deploy
    dir: infrastructure
    cmds:
      - cdk deploy --context env={{.env}}
+   requires:
+     vars:
+       - name: env
+         enum: [dev, stg, prod]
```

こうすると、enum 以外の値を入力できなくなります。

# Task 実行時に引数とコマンドを自動取得する

ここからが本題です。

```shell
$ uvx --from git+https://github.com/gsy0911/taskfile-parser parser --pwd $(pwd) --taskfile-task-name cdk-deploy
env=dev|stg|prod task cdk-deploy
```

という結果が得られます。
