# はじめに

ある日次の記事を見つけてzellijというtmuxに似たターミナルマルチプレクサがあることを知りました。
https://zenn.dev/hirokitakamura/articles/zellij-complete-guide

無くてもweztermのworkspace機能やタブ機能で十分便利なのですが、開発の環境をすぐに立ち上げたい時などはとても便利です。本記事ではいつも使っている方法を紹介します。

# layout機能

zellijにはlayout機能というのがあります。起動時にpaneの分割・名前設定などを指定できるものです。これを使ってIDEっぽく使う事も可能です。ただ、今回はIDEなどではなく単純なターミナルをいい感じに分割して使う方法を紹介します。

## よく使うlayout1

開発用のレイアウトです。開発では、データベース・バックエンド・フロントエンドがそれぞれ別のコマンドで立ち上げる時があります。そのときに1つのペインの中にあるとわかりやすいです。

## よく使うlayout2

coding agent用のレイアウトです。このレイアウトではGitHub Copilot CLIを使うのでデフォルトでcopilotが起動するようにしています。

## zshのショートカット

毎回 `$ zellij -s name -n dev` などと打つのは大変なのでzshの関数を作成しています。デフォルトでは起動したディレクトリの名前がzellijのセッションの名前になります。


# おわりに

Paneの分割にzellijのlayoutを使って日々の開発をしやすくする方法を紹介しました。WezTermも十分にpaneの分割などができますが、それよりも便利になったのでzellijがとても良いです。
