# はじめに

複数の修正を並列で実施したいときが最近は増えてきました。特にAIを使う場合には並列でやるときも多いかと思います。

これまでは`git stash`で退避してブランチを切り替えたり、中途半端な状態でコミットしたりして対応していましたが、作業が複雑になるほどミスが起きやすくなります。そこで`git worktree`を使うことで、ブランチの切り替えなしに複数の作業を同時並行できるようになります。

# Git Worktreeとは

`git worktree`は、1つのリポジトリに対して複数の作業ディレクトリ（working tree）を持てるGitの機能です。通常は1リポジトリ＝1ディレクトリですが、worktreeを追加することで、異なるブランチをそれぞれ別のディレクトリとしてチェックアウトできます。

各worktreeは独立したディレクトリですが、コミット履歴やリモート設定などは共有されるため、`git clone`で複数コピーを作るより軽量です。

## aliasの追加

以下の記事にある`gitconfig`の設定を使って楽に`git worktree`を追加する方法がとても便利です。

https://zenn.dev/hiraoku/articles/56f4f9ffc6d186

上記の記事にあるconfigを一部修正しています。
```gitconfig
[alias]
    # worktree追加（ブランチ名だけ指定すればOK）
    wta = "!f() { \
        branch=\"$1\"; \
        safe_branch=$(echo \"$branch\" | sed 's/\\//-/g' | sed 's/#//g'); \
        repo_name=$(basename \"$(git rev-parse --show-toplevel)\"); \
        path=\"../$repo_name-wt-$safe_branch\"; \
        if git show-ref --verify --quiet \"refs/heads/$branch\"; then \
            git worktree add \"$path\" \"$branch\"; \
        else \
            git worktree add -b \"$branch\" \"$path\"; \
        fi; \
    }; f"
    
    # ブランチ名で削除（パスを探して削除）
    wtr = "!f() { \
        branch=\"$1\"; \
        worktree_path=$(git worktree list --porcelain | grep -B2 \"branch refs/heads/$branch\" | grep \"worktree\" | cut -d' ' -f2); \
        if [ -n \"$worktree_path\" ]; then \
            git worktree remove ${2:+--force} \"$worktree_path\"; \
        else \
            echo \"Worktree for branch '$branch' not found\"; \
        fi; \
    }; f"
    
    # 一覧表示
    wtl = worktree list

```

という設定を`~/.gitconfig`に追加します。以下、各aliasの内容を説明します。

### `wta`（worktree add）

worktreeの追加を楽にするaliasです。処理の流れは以下のとおりです。

1. 引数で受け取ったブランチ名を`safe_branch`に変換する。ブランチ名に含まれる`/`を`-`に、`#`を除去することで、ディレクトリ名として安全な文字列にしています
2. `git rev-parse --show-toplevel`でリポジトリのルートディレクトリ名を取得し、worktreeのパスを`../{リポジトリ名}-wt-{safe_branch}`として組み立てる。例えば、リポジトリ名が`my-app`でブランチが`feature/login`なら、`../my-app-wt-feature-login`が作成先になります
3. `git show-ref`でブランチの存在を確認し、既存ブランチならそのまま`git worktree add`、存在しなければ`-b`オプション付きで新規ブランチを作成しつつworktreeを追加する

### `wtr`（worktree remove）

ブランチ名を指定するだけでworktreeを削除できるaliasです。

1. `git worktree list --porcelain`の出力から、指定したブランチ名に対応するworktreeのパスを検索する
2. パスが見つかればそのworktreeを削除する。第2引数を渡すと`--force`オプションが付きます
3. 見つからなければエラーメッセージを表示する

### `wtl`（worktree list）

`git worktree list`をそのまま短縮したaliasです。現在のworktree一覧をシンプルに確認できます。

## worktreeの追加

```
$ git wta {branch-name}
```

上記の設定では、新しいブランチの追加と同時にworktreeの追加をするようにします。既存のブランチからは新規作成できない点に注意してください。

```
$ git wtl
```

`git wtl`は`git worktree list`のaliasで、現在のworktree一覧を確認できます。

Gitクライアント（Fork）での見た目はこのようになります。コマンドラインだけだと何かが起きたときにどうしても不安なのでGUIで操作できると便利です。



## worktreeの削除

不要になったworktreeは以下のコマンドで削除できます。

```
$ git wtr {branch-name}
```

上記のaliasでは、ブランチ名からworktreeのパスを自動で探して削除してくれます。未コミットの変更が残っている場合は削除が拒否されるので、意図しないデータロスの心配はありません。

なお、aliasを使わない場合は以下のようにパスを直接指定します。

```
$ git worktree remove ../branch-name
```

worktreeを削除してもブランチ自体は残るので、不要であれば別途`git branch -d {branch-name}`で削除してください。
