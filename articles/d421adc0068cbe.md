# マシン・OS

# ウィンドウマネージャー
**[AeroSpace](https://github.com/nikitabobko/AeroSpace)** 

macOS 向けのタイリングウィンドウマネージャーです。ウィンドウを開いた瞬間に自動的に特定のモニタにウィンドウが割り当てられるため、ウィンドウの表示モニタに思考を割く必要がなくなりました。キーボード操作のみでウィンドウの配置や移動が完結するのも大きなメリットです。

# エディタ

## メイン
**PyCharm / WebStorm** (JetBrains IDE)

IntelliJ IDEA を使っていた頃から数えて、もう10年以上 JetBrains 系製品を愛用しています。コードナビゲーションやリファクタリング機能が強力で、大規模な開発には欠かせません。

## サブ
**Neovim**

設定ファイルのちょっとした編集やログの確認などターミナルから離れずに作業したい場合は **Neovim** を使います。起動の速さと手になじんだキーバインドは、他のツールでは代えがたい魅力です。ただ、メインのコーディング用途としてはまだ使えていないです。

# ターミナルエミュレータ
**[WezTerm](https://wezfurlong.org/wezterm/)**
Lua で設定が書ける柔軟性と、GPU アクセラレーションによる描画の速さが気に入っています。ワークスペース機能やタブ機能も多用しており、開発作業において必須のアプリとなっています。

最近話題の **[Ghostty](https://ghostty.org/)**（Zig で書かれた高速なターミナルエミュレータ）への乗り換えも検討しましたが、以下の理由で WezTerm に留まっています。

1. AeroSpace と組み合わせた際に、Ghostty だと挙動が不安定になる場合がある
2. WezTerm の方が体感の動作が軽い

WezTerm は最近のリリース頻度が低く、開発状況に少し不安はありますが、完成度が高く使いやすいため継続して採用しています。

# シェル・プロンプト
**zsh** と **[Starship](https://starship.rs/)** 
シェル自体にはそこまで複雑なカスタマイズを詰め込まず、Starship にプロンプト表示を任せる構成にしています。Git のステータスやコマンドの実行時間などがシンプルかつ高速に表示されるため、非常に快適です。

# dotfiles 管理
はじめにも書いた通り、今年最も大きな変化がこの dotfiles 管理です。構成管理ツールを **Nix** (nix-darwin / home-manager) に完全移行しました。

|             | 以前の構成        | 今の構成                   |
|-------------|--------------|-------------------------|
| 構成管理        | ansible      | nix                     |
| パッケージマネージャ  | brew         | brew + nix (nix-darwin) |
| シンボリックリンク作成 | shell script | nix (home-manager)      |

Ansible は「インストール」は得意なのですが、私の知る限り「アンインストール（状態のクリーンアップ）」が苦手です。そのため、試行錯誤で入れたパッケージが使っていないのに残り続けるのがストレスでした。

Nix への移行により、設定ファイルとインストールするパッケージを宣言的に記述できるようになりました。これにより、設定を書けば環境が再現され、その記述を削除すれば環境からも消えるという快適さが手に入りました。

nix を含む dotfiles は以下のリポジトリで管理しています。
https://github.com/gsy0911/dotfiles

# ブラウザ
**Google Chrome**
なんだかんだで長年使っており手に馴染んでいること、拡張機能のエコシステムが充実していること、そして Google アカウントとの同期が手軽なことが理由です。一時期 Safari への完全移行を試みましたが、特定のサイトでレンダリングが遅かったり、開発時に挙動の差分に悩まされたりしたため断念しました。

# 周辺環境
デバイスはモチベーションと快適さに直結するため、自分に合うものを探求しています。

- **キーボード/トラックパッド**: Mac 純正のキーボードとトラックパッドを使っています。
- **ディスプレイ**: 特にこだわりはなく、23インチを2枚・15インチを1枚の、合計3枚構成です。
- **デスク**: [PREDUCTS](https://preducts.jp/) の昇降デスクを使っています。
- **チェア**: [Herman Miller](https://hermanmiller.co.jp/) のアーロンチェアを使っています。座面がメッシュなので夏場でも涼しく、快適に利用できて良いです。
- **ヘッドフォン**: Bose QuietComfort Headphones を6年くらい使っています。定期的にイヤーパッドを交換することで長年快適に使えています。
- **マイク**: [audio-technica AT2020](https://www.audio-technica.co.jp/product/AT2020) 机からアームを伸ばして宙吊りにして使っています。
- **オーディオインターフェイス**: [YAMAHA AG03](https://jp.yamaha.com/products/music_production/webcasting_mixer/ag03/index.html) XLRケーブルの入力に対応するために使っています。音量調節も細かくできるので良いです。ちょっと大きいのが難点です。

# まとめ

振り返ると、各ツールの選定基準は「快適さ」と「再現性」に集約されます。AeroSpace やWezTerm、JetBrains IDE は日々の操作を快適にするために、Nix による dotfiles 管理は環境の再現性を高めるために導入しました。特に Nix の導入は学習コストが高かったですが、一度構築してしまえば環境を汚すことを恐れずにパッケージを試せるようになったので、結果として良い投資でした。2026年も引き続き、快適な開発環境を追求していきたいです。
