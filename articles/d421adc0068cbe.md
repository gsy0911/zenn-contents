# はじめに
2026年の現在の開発環境を棚卸ししておきます。
今年は特に dotfiles の管理方法を大きく刷新しました。そのあたりの経緯も含めて記録に残しておきたいと思います。

# バックグラウンド

業務では、フロントエンド・バックエンド・インフラ構築まで幅広く携わっています。
主な技術スタックとして、フロントエンドは Next.js、バックエンドは Python と PHP、インフラは AWS CDK (TypeScript) を使用しています。

リモートサーバーへ SSH して作業することはほとんどなく、ローカル環境での開発がメインです。
また、複数の端末を利用しているため、どの環境でも同じ使い勝手を実現することを強く意識しています。

# マシン・OS

端末は主に以下の2つを使っています。ここ8年ほどはずっと Mac ユーザーです。

- 個人端末: **MacBook Pro (M1 Pro)**
- 会社支給: **MacBook Air (M3)**

ドッキングステーションには [サンワサプライ 400-VGA023](https://direct.sanwa.co.jp/ItemPage/400-VGA023) を使っています。これを使うことで3画面まで出力できるようにしています。
ディスプレイは 23インチを2枚（横置き）、15インチを1枚（PC本体、あるいはモバイルモニタ）という構成で、情報を広く表示できるようにしています。

# ウィンドウマネージャー
**[AeroSpace](https://github.com/nikitabobko/AeroSpace)** を導入しています。
macOS 向けのタイリングウィンドウマネージャーです。
Magnet などの配置ツールとは異なり、ウィンドウを開いた瞬間に自動的に敷き詰められる（タイリングされる）ため、ウィンドウの位置調整に思考を割く必要がなくなりました。
キーボード操作のみでウィンドウの配置や移動が完結するのも大きなメリットです。

以下の記事にて AeroSpace の導入手順や設定について詳しくまとめています。
https://zenn.dev/gsy0911/articles/c009044a4f7026


# エディタ

## メイン
**PyCharm / WebStorm** (JetBrains IDE)
IntelliJ IDEA の頃から数えて、もう10年以上 JetBrains 系製品を愛用しています。
コードナビゲーションやリファクタリング機能が強力で、大規模な開発には欠かせません。

## サブ
**Neovim**
設定ファイルのちょっとした編集やログの確認、Git 操作の合間など、ターミナルから離れずに作業したい場合は **Neovim** を使います。
起動の速さと手になじんだキーバインドは、他のツールでは代えがたい魅力です。

# ターミナルエミュレータ
**[WezTerm](https://wezfurlong.org/wezterm/)** を愛用中です。
Lua で設定が書ける柔軟性と、GPU アクセラレーションによる描画の速さが気に入っています。
ウィンドウ分割やタブ機能も多用しており、開発作業において必須のアプリとなっています。

最近話題の **Ghostty** への乗り換えも検討しましたが、以下の理由で WezTerm に留まっています。

- WezTerm の方が体感の動作が軽い
- AeroSpace と組み合わせた際に、Ghostty だと挙動が不安定になる場合があった

WezTerm は最近のリリース頻度が低く、開発状況に少し不安はありますが、完成度が高く使いやすいため継続して採用しています。

# dotfiles 管理
構成管理ツールを **Nix** (nix-darwin / home-manager) に完全移行しました。

以前の構成：
- Shell script でシンボリックリンクを作成
- Homebrew でパッケージ管理
- Ansible で設定反映

以前の課題として、Ansible 等は「インストール」は得意ですが「アンインストール（状態のクリーンアップ）」が苦手という点がありました。
試行錯誤で入れたツールがゴミとして残り続けるのがストレスでした。

Nix への移行により、設定ファイルとインストールするパッケージを宣言的に記述できるようになりました。
これにより、プログラミング言語のように設定コードを書けば環境が再現され、その記述を削除すればきれいさっぱり環境からも消えるという安心感が手に入りました。

# ブラウザ
**Google Chrome** を使用しています。
なんだかんだで長年使っており手に馴染んでいること、拡張機能のエコシステムが充実していること、そして Google アカウントとの同期が手軽なことが理由です。
一時期 Safari への完全移行を試みましたが、特定のサイトでレンダリングが遅かったり、開発時に挙動の差分に悩まされたりしたため断念しました。

# パスワードマネージャー
Apple 純正の「**パスワード**」アプリを使っています。
Mac / iPhone / iPad 間での同期が iCloud 経由で自動的に行われるため、何も意識しなくて良いのが楽です。
Touch ID でサクッと入力できる体験も優れています。特に強いこだわりがない限り、純正が一番安定していると感じます。

# 周辺環境
身体に触れるデバイスはモチベーションと疲労度に直結するため、自分に合うものを探求しています。

- **キーボード/トラックパッド**: Mac 純正のキーボードとトラックパッドを使っています。
- **ディスプレイ**: 特にこだわりはなく、23インチを2枚・15インチを1枚の、合計3枚構成です。
- **デスク**: [PREDUCTS](https://preducts.jp/) の昇降デスクを使っています。
- **チェア**: [Herman Miller](https://hermanmiller.co.jp/) のアーロンチェアを使っています。座面がメッシュなので夏場でも涼しく、快適に利用できて良いです。

# まとめ
ツールの選定基準は「思考を邪魔しないこと」と「再現性」です。
特に Nix の導入は学習コストが高かったですが、一度構築してしまえば環境を汚すことを恐れずにツールを試せるようになったので、結果として良い投資でした。
2026年も引き続き、快適な開発環境を追求していきたいです。
