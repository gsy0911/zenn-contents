## worktreeの追加

```
$ git wta {branch-name}
```

上記の設定では、新しいブランチの追加と同時にworktreeの追加をするようにします。既存のブランチからは新規作成できない点に注意してください。

```
$ git wtl
```


GitClient（fork）での見た目はこのようになります。コマンドラインだけだと何かが起きたときにどうしても不安なのでGUIで操作できると便利です。
