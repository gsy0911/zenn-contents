# 今まで

タブの表示名の制御はWezTermの範囲だと思っていたので、WezTermの機能でタブの名前をゴリゴリ編集していました。それが次のような関数です。

# これから

## zshでのタイトルの変更

zshでは次のコマンドでタイトルの変更ができます。


```
$
```

WezTermは、このタイトルをタブの表示に使っているのでタイトルを変更すればタブにも反映されます。これを使ってリポジトリ直下からのディレクトリを表示するようにしています。

```
$
```

これらのコマンドをzshのhookの機能を使って、ディレクトリ移動した際に自動的に動くようにします。

周りのアイコンなどの装飾についてはWezTerm側で制御しています。

## 便利になった点

shellで文字列を組めるのでとても楽です。

また、自動的にタイトルが変更するので、タブの名前が切り替わるのが早くなりました。これまではWezTermのタブを移動したときにしか変更ができなかったのですが（WezTermのhookのタイミング的に仕方なし）、それがzshのhookのタイミングで切り替わるようになったのでとても便利です。
